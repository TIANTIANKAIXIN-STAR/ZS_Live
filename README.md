# ZS_Live

云渲染 / 实时推流平台 —— 基于 **Unreal Engine + WebRTC(WHEP) + MediaMTX** 的低延迟
云游戏 / 云推流解决方案。非 Pixel Streaming 方案，自研调度与控制通道。

核心能力：
- GPU 权重准入调度（防止单卡超卖）
- NVENC 硬编码（4K@30/60 低延迟）
- 按需关键帧（切换前台标签瞬时恢复，无卡顿）
- 过载拒绝闸（平均帧率过低时拒绝新流，不影响已运行流）
- 冷启动串行化 + 实例预热池
