# 控制通道协议（Control Channel Protocol）

本文档定义浏览器 ↔ 调度服务 ↔ UE 实例之间的 WebSocket 消息格式。所有消息均为 UTF-8 JSON 文本帧，包含一个顶层字段 `type`。

```
浏览器 (player.js)                调度服务 (Node)                UE 实例 (StreamForge)
     │  WS /ws?token=xxx   ────────►│                               │
     │                              │◄──────── WS /agent  ──────────│ (Bearer AgentToken + X-SF-InstanceId)
     │                              │      hello / heartbeat        │
     │◄──── assigned / queue ──────│                               │
     │  input / command   ─────────►│────── input / command ──────►│
     │◄──── ue_event ───────────────│◄───────────── event ─────────│
```

- 浏览器连接 `ws://<host>:3000/ws?token=<会话令牌>`（由 `POST /api/session` 返回）。
- UE 实例连接 `ws://<host>:3000/agent`，请求头：
  - `Authorization: Bearer <AgentToken>`（由 `-SFAgentToken` 命令行传入）
  - `X-SF-InstanceId: <实例ID>`（由 `-SFInstanceId` 传入）

---

## 1. 浏览器 → 服务（/ws）

### 1.1 `input` — 原始键鼠事件（归一化）

播放器捕获本地键鼠后归一化发送。坐标系为**相对画布比例**（0.0~1.0），UE 端乘以实际窗口分辨率。

```json
{
  "type": "input",
  "subtype": "mouse_move",
  "x": 0.523,
  "y": 0.417
}
```

| subtype | 附加字段 | 说明 |
|---|---|---|
| `mouse_move` | `x`, `y` | 归一化坐标（0~1） |
| `mouse_down` / `mouse_up` | `x`, `y`, `button` | button: `"left"` / `"right"` / `"middle"` |
| `wheel` | `delta` | 浏览器 `wheel.deltaY`（正=向下）。UE 插件转为 Windows 约定（正=向上）并归一化为 ±1 刻度 |
| `key_down` / `key_up` | `code`, `mods` | code 为 JS `KeyboardEvent.code`（如 `"KeyW"`、`"ShiftLeft"`）；mods: `["ctrl","shift","alt","meta"]` |

### 1.2 `command` — 自定义指令（透传给 UE）

```json
{
  "type": "command",
  "action": "load_level",
  "payload": { "map": "/Game/Maps/Demo.umap" }
}
```

`action` 与 `payload` 完全由业务自定义，服务端原样转发给当前绑定的 UE 实例。

### 1.3 `pong` — 心跳应答

```json
{ "type": "pong" }
```

## 2. 服务 → 浏览器（/ws）

### 2.1 `assigned` — 会话已分配实例

```json
{
  "type": "assigned",
  "sessionId": "s_aB3xY",
  "whepUrl": "http://192.168.1.10:8889/zslive/s_aB3xY/whep",
  "instanceId": "i_k9Qz2"
}
```

浏览器收到后立即用 `whepUrl` 发起 WHEP 拉流（RTCPeerConnection + SDP offer POST）。

### 2.2 `queue_update` — 排队位置

```json
{
  "type": "queue_update",
  "position": 2,
  "totalWaiting": 5
}
```

### 2.3 `ue_event` — UE 侧上报事件（透传）

```json
{
  "type": "ue_event",
  "name": "level_loaded",
  "data": { "map": "Demo" }
}
```

### 2.4 `session_ended` — 会话结束（实例回收/崩溃）

```json
{ "type": "session_ended", "reason": "instance_dead" }
```

reason 可能值：`released`（用户主动结束）、`idle_timeout`、`instance_dead`、`server_shutdown`。

### 2.5 `ping` — 服务端心跳（30s）

浏览器应在 10s 内回 `pong`，超时判定断线（10s 宽限后结束会话）。

## 3. UE ↔ 服务（/agent）

### 3.1 UE → 服务

**`hello`**（连接后立即发送，服务端以此将连接与实例绑定）：

```json
{
  "type": "hello",
  "instanceId": "i_k9Qz2",
  "engine": "5.7",
  "version": "1.0.0"
}
```

**`heartbeat`**（每 2s）：

```json
{
  "type": "heartbeat",
  "fps": 59.8,
  "encodeMs": 3.2,
  "rtmpQueue": 12,
  "bitrate": 7820000,
  "rtmpConnected": true
}
```

**`event`** — 业务事件上报（透传给浏览器，变为 `ue_event`）：

```json
{
  "type": "event",
  "name": "player_score",
  "data": { "score": 100 }
}
```

**`pong`** — 服务端 `ping` 的应答。

### 3.2 服务 → UE

**`input` / `command`** — 与第 1 节格式完全相同，服务端原样转发。UE 端：
- `input` → 转换为 `FSlateApplication::ProcessKeyDownEvent / ProcessMouseMoveEvent` 等注入
- `command` → 广播到 `UStreamForgeSubsystem` 的 `OnCommand` 委托（蓝图/ C++ 均可订阅）

**`ping`** — 心跳（UE 端 10s 无心跳上报判定连接断开并重连）。

## 4. UE 插件蓝图侧 API（消费/发送消息）

| 节点 | 类型 | 说明 |
|---|---|---|
| `OnCommand` | 事件（委托） | 收到浏览器 `command` 时触发，参数为 `Name`（action）+ `String`（payload JSON） |
| `OnControlEvent` | 事件（委托） | 控制通道原始事件（Connected / Disconnected / Reconnected） |
| `SendEventToBrowser` | 函数 | 向浏览器发送 `ue_event`，参数 `Name` + `Data`（JSON 字符串） |
| `SetBitrate` | 函数 | 动态调整视频码率（bps） |
| `RequestKeyFrame` | 函数 | 立即请求一个关键帧（画面花屏自救） |
| `GetStatsJson` | 函数 | 返回最新统计 JSON（fps/encodeMs/rtmpQueue/bitrate） |

### 示例：浏览器点击"开始游戏"按钮 → UE 切换关卡

浏览器：

```js
ws.send(JSON.stringify({
  type: "command",
  action: "load_level",
  payload: JSON.stringify({ map: "/Game/Maps/Game.umap" })
}));
```

UE 蓝图（订阅 `OnCommand`）：

```
Event OnCommand (Name Action, String Payload)
├─ Branch (Action == "load_level")
│   ├─ Get JSON String Field (Payload, "map") → LevelName
│   └─ Open Level (by Name) (LevelName)
└─ (default) Print String (Payload)
```

UE 完成后回报：

```
SendEventToBrowser("level_loaded", "{\"map\":\"Game\"}")
```

## 5. 时序与超时约定

| 项 | 值 | 说明 |
|---|---|---|
| UE 心跳 | 2s | 超过 10s 未收到 → 服务端标记实例失联 |
| 服务端 ping | 30s | 浏览器/UE 10s 内须回 pong |
| 浏览器断线宽限 | 10s | 超过则会话结束、实例回收 |
| UE 控制通道重连 | 3s 间隔 | 指数退避（3s → 6s → 12s，上限 60s） |
| 实例空闲回收 | 默认 300s | 无会话且非预热池保留实例 |
