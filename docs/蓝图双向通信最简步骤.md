# ZS_Live 最简「网页 ↔ UE」双向通信（蓝图版，零代码）

适用前提：
- StreamForge 插件已放进工程并启用，UE 已能推流、浏览器能看到画面（看 `docs/UE插件集成指南.md` 第 1~4 节）。
- 你会蓝图（Blueprint），不写 C++。
- 前端这里**不需要你会写 JS**：复制一个现成 HTML 改两处即可。

双向链路：
```
网页按钮 ──sendCommand("切场景","2")──> 控制通道(WebSocket) ──> UE 蓝图 OnCommand
网页  <──SendEventToBrowser("场景已切","2")── 控制通道 <── UE 蓝图
```

---

## 第 1 部分：UE 端（纯蓝图）

### 步骤 1 — 拿到 StreamForge 子系统
在任意蓝图的事件图里（推荐「关卡蓝图 Level Blueprint」，或某个一直存在的 Actor）：
1. 空白处右键 → 搜索 **`Get Stream Forge Subsystem`**。
   - 若搜不到，就右键搜 **`Get Game Instance`**，从它的引脚拖出 → 搜 **`Get Subsystem`** → 类选 **`StreamForgeSubsystem`**。
2. 这个节点就是后面要用的「桥」。

### 步骤 2 — 绑定「收到命令」事件
1. 从步骤 1 那个节点的返回值引脚拖出 → 搜 **`Assign On Command`**（或「绑定事件到 On Command」）。
2. 会生成一个事件节点，带两个输出引脚：
   - **Name**（字符串）：网页发来的命令名，如 `切场景`
   - **Payload**（字符串）：网页发来的数据，如 `2`

### 步骤 3 — 在事件里做你的事
最简单的示范（直接照抄）：
1. 拖一个 **`Print String`**，连到事件执行线；内容用 `Name` + `Payload` 拼一下，方便你确认收到了。
2. 想按命令名分支：加一个 **`Branch`** + **`Equal (String)`**，拿 `Name` 和常量（如 `切场景`）比。
   - 例：Name == `切场景` 时，用 `Payload`（如 `2`）去 **`Open Level`**（关卡名 = Payload），或移动某个 Actor、改材质等。

### 步骤 4 — 回发一个事件给网页
1. 在步骤 3 的逻辑之后，调用 **`Send Event to Browser`**（在子系统节点上，或直接搜索）。
2. 填两个字符串：
   - **Name**：如 `场景已切`
   - **Data**：如 `Payload`（把网页发来的原样回传，或写任意字符串）

> 至此 UE 侧完成：收到命令 → 做事 → 回发事件。打包照常（插件从命令行读配置，无需改项目设置）。

## 第 2 部分：网页端（复制一个文件）

### 步骤 5 — 放一个 HTML 文件
把下面这段**整段**保存成一个文件，比如 `web/mycontrol.html`（放在平台 `web/` 目录下，这样能直接用 `http://<服务器>:3100/mycontrol.html` 打开，且 `/sdk/zslive-parent.js` 同域名、无跨域问题）。

> 复制前先改两处（文件里已用 `★改这里★` 标出）：
> - `BASE_URL`：你的服务器地址，如 `http://192.168.1.10:3100`（本机用 `http://127.0.0.1:3100`）
> - `TEMPLATE`：后台「模板」里那个模板的数字 ID（没有就留空 `''`）

```html
<!doctype html>
<html lang="zh">
<head>
  <meta charset="utf-8" />
  <title>ZS_Live 双向通信演示</title>
  <style> body{font-family:sans-serif} #app{width:960px;height:540px;border:1px solid #ccc} button{margin:6px;padding:8px 14px} </style>
</head>
<body>
  <h3>① 画面（自动拉流，鼠标可直接操作 UE）</h3>
  <div id="app"></div>

  <h3>② 给 UE 发命令</h3>
  <button onclick="sendCmd('切场景','2')">命令：切场景 → 2</button>
  <button onclick="sendCmd('hello','来自网页')">命令：hello</button>

  <h3>③ UE 回发的事件</h3>
  <pre id="log">（等待 UE 回发…）</pre>

  <!-- ★改这里★：BASE_URL = 你的服务器地址:端口 -->
  <script src="http://127.0.0.1:3100/sdk/zslive-parent.js"></script>
  <script>
    const BASE_URL = 'http://127.0.0.1:3100';   // ★改这里★
    const TEMPLATE = '1';                         // ★改这里★ 模板ID，没有就写 ''

    const stream = ZsLive.mount({
      container: '#app',
      baseUrl: BASE_URL,
      template: TEMPLATE,
      streamId: 'demo',
    });

    // 收到 UE 回发的事件
    stream.on('ue', (e) => {
      document.getElementById('log').textContent =
        '收到 UE 事件：name=' + e.name + '，data=' + e.data;
    });
    stream.on('inputready', () => console.log('UE 已就绪，可以发命令了'));

    // 给 UE 发命令（Name + 数据，都是字符串）
    function sendCmd(name, data) {
      stream.sendCommand(name, data);
      document.getElementById('log').textContent = '已发送命令：' + name + ' / ' + data;
    }
  </script>
</body>
</html>
```

### 步骤 6 — 打开并验证
1. 浏览器访问 `http://<服务器>:3100/mycontrol.html`。
2. 画面出现、约几秒后显示 UE 画面（点击画面即可用鼠标键盘操作 UE）。
3. 点页面上的「命令：切场景 → 2」按钮 → UE 控制台/画面应打印收到 `切场景` / `2`，并执行你的蓝图逻辑；随后页面下方出现 `收到 UE 事件：name=场景已切，data=2`。

## 协议速查（照着用就行）

| 方向 | 你写什么 | UE 收到 / 网页收到 |
|---|---|---|
| 网页→UE | `stream.sendCommand('命令名','数据')` | 蓝图 `On Command`：Name=`命令名`，Payload=`数据` |
| UE→网页 | `Send Event to Browser('事件名','数据')` | `stream.on('ue', e=>)`：`e.name`=`事件名`，`e.data`=`数据` |

- 命令名、事件名、数据**都是字符串**。最简单的用法：数据直接传 `"2"`、`"level2"` 这种字符串，蓝图里不用解析。
- 想传多个字段：把数据拼成 JSON 字符串（如 `{"x":1,"y":2}`）。UE 收到的是字符串，蓝图里要解析；网页收到也是字符串，用 `JSON.parse(e.data)` 还原。

## 常见坑

1. **发的太早没反应**：等网页控制台打印「UE 已就绪」（或 `inputready` 事件）后再发命令，否则命令可能早于连接建立而丢失。
2. **改完蓝图要重新打包 UE**：插件在打包程序里才推流，编辑器里不推。
3. **本机测试跨域**：HTML 必须和 `/sdk/...` 同域名（都走 `http://<服务器>:3100/...`）。不要直接双击用 `file://` 打开，那样加载不到 SDK 且 WebSocket 会被浏览器拦。
4. **公网必须 HTTPS**：若服务器在公网，页面和 `BASE_URL` 都要 `https://`，否则浏览器不让用摄像头/麦克风类权限、WebSocket 也可能被拦。
5. **数据记得是字符串**：`sendCommand('a', 2)` 里的 `2` 会被当字符串；蓝图 `Payload` 永远是字符串，别拿去和整数直接比。
